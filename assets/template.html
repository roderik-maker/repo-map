    NameLinesCharacters

    Counted from committed git objects, so uncommitted work in progress is not included. Lines are newline-terminated lines, as wc -l counts them, plus a final line with no newline. Characters are Unicode code points, newlines included. Bar segments and treemap colours show the file type. History is sampled along the main (first-parent) line of commits; a file that was renamed or moved counts as one removed and one added. Copied paths and commands use the checkout path on this machine, so they point at the working copy, not the commit shown.
